# Tmux 常用快捷键速查与进阶技巧

> **前缀键说明**：当前配置已将默认前缀修改为 **`Ctrl-a`**（后文统一记为 `Prefix`）。

---

## 一、常用快捷键速查

### 1. 基础与会话控制

| 快捷键 | 动作 | 说明 |
| :--- | :--- | :--- |
| `Prefix` + **`d`** | 挂起会话 (Detach) | 会话保持后台运行，返回外层 Shell |
| `Prefix` + **`s`** | 交互式选择会话 | 查看并快速切换不同的 tmux session |
| `Prefix` + **`Ctrl-r`** | **重载配置** | 立即重新加载 `~/.tmux.conf`，并显示提示信息 |
| `Prefix` + **`Ctrl-a`** 或 **`a`** | 发送原生 `Ctrl-a` | 跳到终端行首（防止与 bash/emacs 快捷键冲突） |

### 2. 窗口管理 (Windows)

| 快捷键 | 动作 | 说明 |
| :--- | :--- | :--- |
| `Prefix` + **`c`** | 新建窗口 | **自动保持当前目录** (`pane_current_path`) |
| `Prefix` + **`1` ~ `9`** | 直达指定编号窗口 | 基数为 1，直接单手按键直达 |
| `Prefix` + **`Ctrl-h`** | 切换到上一窗口 | 绑定 `select-window -t :-`（支持按住 Ctrl 连按 `a` `h`） |
| `Prefix` + **`Ctrl-l`** | 切换到下一窗口 | 绑定 `select-window -t :+`（支持按住 Ctrl 连按 `a` `l`） |
| `Prefix` + **`,`** | 重命名当前窗口 | 自定义底部状态栏显示的窗口标签名 |
| `Prefix` + **`N`** | **恢复自动重命名** | 恢复当前窗口根据正在运行的命令自动重命名 |
| `Prefix` + **`&`** | 关闭当前窗口 | 会提示确认 `(y/n)` |

### 3. 窗格管理 (Panes)

| 快捷键 | 动作 | 说明 |
| :--- | :--- | :--- |
| `Prefix` + **`%`** | **左右垂直分屏** | 自动保持当前目录 |
| `Prefix` + **`"`** | **上下水平分屏** | 自动保持当前目录 |
| `Prefix` + **`h` / `j` / `k` / `l`** | **窗格焦点移动** | Vim 风格导航（左/下/上/右） |
| `Prefix` + **`H` / `J` / `K` / `L`** | **窗格尺寸调节** | 大写字母，每次调整 5 格，**支持按住连按微调** (`-r`) |
| `Prefix` + **`z`** | 最大化/恢复窗格 | 临时将当前窗格占满窗口，再次按下还原 |
| `Prefix` + **`q`** | 显示窗格编号与尺寸 | 延长至 2 秒高亮显示，期间按下对应数字直接跳过去 |
| `Prefix` + **`x`** | 关闭当前窗格 | 会提示确认 `(y/n)`（亦可直接在 shell 中敲 `exit`） |
| `Prefix` + **`Ctrl-k`** | **清空当前历史** | 清空当前窗格的滚回缓冲区 (`clear-history`) |

### 4. 浏览历史与 Vi 复制模式

配置已启用 `mode-keys vi` 与长达 65,536 行的缓冲区：

| 快捷键 | 阶段 | 说明 |
| :--- | :--- | :--- |
| `Prefix` + **`[`** | 进入复制/翻页模式 | 此时可通过鼠标滚轮，或 Vim 快捷键 `k`/`j`/`Ctrl-u`/`Ctrl-d` 翻页浏览 |
| **`v`** | 复制模式内 | 开始字符选择 (`begin-selection`，类比 Vim 的 `v`) |
| **`V`** | 复制模式内 | 切换矩形块选择 (`rectangle-toggle`，类比 Vim 的 `Ctrl-v`) |
| **`y`** | 复制模式内 | 复制选区到 tmux 剪贴板并退出复制模式 |
| `Prefix` + **`]`** | 正常终端状态 | 将刚刚复制的内容粘贴出来 |
| **`q`** / **`Esc`** | 复制模式内 | 放弃并直接退出浏览模式 |

## 二、进阶技巧

### 技巧 1：`Prefix + <` / `>` 窗格输入锁定（防止误触灾难）
* **触发场景**：某个窗格正在执行高危操作（如生产机环境执行脚本、长时间编译、数据库迁移），防止切错窗格误敲 `Ctrl-c` 或误触键盘。
* **操作**：
  * 按 **`Prefix + <`**：锁定当前窗格的键盘输入（`display-message "input disabled"`）。
  * **状态栏联动**：左侧的 `[#S:#I.#P]` 会**立即从黄褐色变成亮红色警示**！
  * 按 **`Prefix + >`**：解除锁定，恢复正常输入。

### 技巧 2：`Prefix + P` 前缀穿透切换（嵌套 Tmux 终极解法）
* **痛点**：在本地打开了 tmux，然后通过 SSH 登录到远程服务器，远程服务器里也开着 tmux。此时按下 `Ctrl-a` 会被本地截获，无法直接向远程发送指令。
* **解法**：
  * 在本地按下 **`Prefix + P`**：tmux 会提示 `passthrough enabled`，并将本地前缀动态切换为 **`Ctrl-b`**。
  * **效果**：此时你按 `Ctrl-a` 会直接穿透到远程 tmux；控制本地 tmux 时，改用 `Ctrl-b`。
  * 完成远程操作后，在本地再次按下 **`Ctrl-b P`**，本地提示 `passthrough disabled`，前缀无缝恢复回 `Ctrl-a`。

### 技巧 3：窗格拆分与跨窗口重组（`!` 与 `@`）
* **窗格变独立窗口**：当前分屏太拥挤时：
  * 按 **`Prefix + !`**：把当前窗格“弹射”出去，独立变成一个新窗口。
* **窗口/窗格拉入合并**：
  * 按 **`Prefix + @`**：屏幕下方会弹出提示 `create pane from:`。
  * 输入源目标位置（例如输入 `2.1` 表示第 2 窗口的第 1 窗格，或直接输入窗口号 `2`），就会将目标抓取到当前窗口并自动分屏合并。

### 技巧 4：状态栏指示器视觉辅助
* **前缀激活捕捉**：右侧状态栏配置了 `#{?client_prefix,#[fg=colour160],#[fg=colour61]}`。按下 `Ctrl-a` 时，右侧日期时间前的连接线会**瞬间变红**，直观提醒当前正处于前缀等待状态。
* **主机名覆盖**：右侧状态栏会优先检查 `$HOME/.name`，如果存在该文件则优先显示别名，方便多机器运维时区分机器身份。

### 技巧 5：本地专属配置无侵入隔离
* 配置文件末尾引入了：
  ```tmux
  if-shell "[ -f ~/.tmux_local.conf ]" 'source ~/.tmux_local.conf'
  ```
* 若在特定机器上需要自定义微调或临时配置，只需写入 `~/.tmux_local.conf`，既能即时生效，又不会污染 Git 仓库的主配置。
