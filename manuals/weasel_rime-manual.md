# Rime（小狼毫 Weasel）+ 雾凇拼音使用手册

> **工具说明**：[Rime（中州韵输入法引擎）](https://rime.im/) 是一款高度可定制、开源且保护隐私的跨平台输入法框架；在 Windows 平台上以前端 **小狼毫（Weasel）** 运行。**[雾凇拼音（rime-ice）](https://github.com/iDvel/rime-ice)** 是目前社区公认词库质量最高、开箱即用的开源全拼配置包。本手册聚焦于 **Windows 小狼毫环境下的全拼方案**，涵盖底层机制、日常高频击键速查与深度定制技巧。

---

## 一、基本概念与核心机制

### 1. 核心架构与目录分工

Rime 的运转依赖三层架构的协同：

```text
┌────────────────────────────────────────┐
│     小狼毫 Weasel（Windows 前端界面）  │  负责：候选窗口渲染、托盘状态、快捷键钩子
└──────────────────┬─────────────────────┘
                   │ TSF / IMM
┌──────────────────▼─────────────────────┐
│       Rime 引擎内核（librime）         │  负责：拼音切分、分词加权、语言模型计算
└──────────────────┬─────────────────────┘
                   │ 读取配置与词库
┌──────────────────▼─────────────────────┐
│    雾凇配置包（rime-ice 配置与词库）   │  负责：全拼规则、字词典、Lua 扩展插件
└────────────────────────────────────────┘
```

Windows 下主要有两个关键目录，**切勿混淆**：

<!-- markdownlint-disable MD013-->

| 目录类型     | 典型路径                                 | 职责与修改规则                                      |
| :----------- | :--------------------------------------- | :-------------------------------------------------- |
| 用户配置目录 | `%APPDATA%\Rime`                         | 核心工作区。所有方案配置文件/自定义配置仅限此目录。 |
| 程序安装目录 | `C:\Program Files\Rime\weasel-<版本号>\` | 程序只读区。存放 Weasel 资源。严禁手动修改此目录。  |

<!-- markdownlint-enable MD013-->

### 2. 配置生效哲学：补丁机制（Patch）与重新部署（Deploy）

1. **不修改官方原文件原则**：
   - 雾凇拼音会持续迭代词库与功能。若直接修改 `rime_ice.schema.yaml` 或
     `weasel.yaml`，后续使用 Git 更新雾凇拼音时必然发生冲突被覆盖。
   - **正确方式**：利用 Rime 的 Patch 补丁机制，在用户目录中创建并编辑
     `*.custom.yaml` 文件（如 `rime_ice.custom.yaml` 或 `weasel.custom.yaml`），
     按键与功能在补丁中覆盖。
2. **重新部署（Deploy）**：
   - Rime 的配置文件（YAML）并非每次敲字时实时动态读取，而是在“重新部署”时被预编
     译为高性能的二进制缓存（输出至 `%APPDATA%\Rime\build\` 目录）。
   - 任何配置或词库改动后，**必须执行重新部署**才能生效。

### 4. 符号与特殊字符引导输入（v 模式重构）

> **`v` 模式**（全拼使用 `v` 引导，对应 `symbols_v.yaml`）。
> 无需切换英文或寻找软键盘，中文状态下键入 `v` + 分类简码即可调出各类图形、序号、文字与表情。

## 三、进阶技巧

### 技巧 1：`v` 模式深度掌握（符号引导 vs 金额计算器）

- **痛点场景**：新版雾凇拼音将符号引导收敛至 `v` 键，
  而原有的数字大写转换与算术运算也挂载在 `v` 键上，
  初学者容易对 `v` 模式的触发逻辑产生混淆。
- **分流机制解析**：
  - **`v` + 字母/简码**（如 `vfh`、`vft`、`vjt`、`vhelp`）$\rightarrow$ **触发
    `symbols_v.yaml` 符号翻译器**，输出特殊符号、标点与表情。
  - **`v` + 纯数字/浮点数**（如 `v12345.67`）$\rightarrow$ **触发
    Lua 金额与数字转换器**，输出财务大写与中文数字。
  - **`v` + 数学算式**（如 `v384*2.5`）$\rightarrow$ **触发
    Lua 简易计算器**，直接计算并给出数值结果。
- **操作演示**：
  - **大写数字/金额**：输入 `v` + 纯数字。例如键入：
    ````text
    v12345.67
    ```
    候选栏立即展示：
    - 壹万贰仟叁佰肆拾伍元陆角柒分（财务大写规范）
    - 一万二千三百四十五点六七（普通中文小写数字）
    - 壹万贰仟叁佰肆拾伍点陆柒
    ````
  - **实时算术求值**：输入 `v` + 算式，例如：
    ```text
    v384*2.5
    ```
    候选栏将自动通过内置 Lua 计算并给出结果 `960`，按下空格即可直接上屏。
- **效果**：一键兼顾“极速符号录入”、“零差错财务大写”与“随手算术求值”，
  彻底免去切出独立小工具的麻烦。

### 技巧 2：动态日期、时间与农历毫秒级直出

- **痛点场景**：日常记录工作日志、Git Commit、编写会议纪要或发送日程通知时，
  频繁查日历并手动敲入当前年、月、日、分、秒格式繁琐。
- **操作**：输入雾凇拼音内置的动态预设缩写（基于当前系统时钟）：
  - 输入 `rq`（日期）：提供 `2026-11-12`、`2026年11月12日`、`20261112`
  - 输入 `sj`（时间）：提供 `09:30`、`09:30:15`
  - 输入 `dt`（日期时间）：提供 `2026-11-12T09:30:15+08:00`（ISO 8601 标准格式）
  - 输入 `xq`（星期）：提供 `星期四`、`Thursday`、`周四`
  - 输入 `nl`（农历）：提供 `丙午年十月初四` 等干支农历记法
- **效果**：无需手动敲击连接符与当前时间，击键两次即可完成标准化时间戳上屏。

### 技巧 3：以形查音（`u` 模式拆字与部件组字）

- **痛点场景**：阅读古籍、文献或遇到生僻字（如“犇”、“焱”、“淼”、“惢”），
  不知道具体汉语拼音读法，无法用拼音常规输入。
- **操作**：
  - 在拼音输入状态下，输入引导符 **`u`** 进入部件组字模式。
  - 将汉字拆为熟悉的部件，依序拼出部件的拼音。
  - **示例 1（叠字拆分）**：
    - 输入 `uhuohuohuo`（三个火）$\rightarrow$ 呈现 **焱**（同时标注拼音 `yàn`）
    - 输入 `uniuniuniu`（三个牛）$\rightarrow$ 呈现 **犇**（同时标注拼音 `bēn`）
  - **示例 2（合体字拆分）**：
    - 输入 `uriyue`（日 + 月）$\rightarrow$ 呈现 **明**
    - 输入 `umuhe`（木 + 禾）$\rightarrow$ 呈现 **秫**
- **效果**：既能顺利打出从未学过的生僻汉字，又能即时反查其标准读音。

### 技巧 4：精准私有短语直达（`custom_phrase.txt`）

- **痛点场景**：电子邮箱、长地址、个人手机号、公司开票税号、代码常用 Boilerplate
  等高频固定文本，若依赖拼音自造词不仅击键长，还会被词频算法冲散打乱。
- **操作**：
  1. 打开 `%APPDATA%\Rime` 目录，找到或新建文件 `custom_phrase.txt`。
  2. 按照 **`文字内容 <Tab制表符> 触发编码 <Tab制表符> 权重`** 的格式编辑
     （**注意：字段之间必须为 Tab 键，不能是空格**）：

     ```tsv
     # 用户私有自定义短语
     user@domain.com mail 1
     13800138000 phone 1
     91310000XXXXXXXXXX tax 1
     https://github.com/iDvel/rime-ice rice 1
     ```

  3. 保存文件，按下 `Ctrl + Alt + \` 重新部署。
- **效果**：无论输入法如何学习自然语言，只要键入 `mail`，自定义邮箱永远稳稳排在首候选，绝不产生干扰。

### 技巧 5：规范 YAML 补丁机制（定制候选字数与选字键）

- **痛点场景**：默认候选词数量为 5 个不够看，想改成 7 个或 9 个；或者希望用分号
  `;` 选第二候选、单引号 `'` 选第三候选来提升录入速度，但直接改
  `rime_ice.schema.yaml` 会被上游更新冲刷。
- **操作**：
  1. 在 `%APPDATA%\Rime` 下新建文件 `rime_ice.custom.yaml`。
  2. 编写针对 `rime_ice` 方案的 patch 内容：
     ```yaml
     # rime_ice.custom.yaml
     patch:
       # 调整候选词数量为 7 个
       "menu/page_size": 7

       # 自定义按键绑定（分号选第2候选，单引号选第3候选）
       "key_binder/bindings/+":
         - { when: has_menu, accept: semicolon, send: 2 }
         - { when: has_menu, accept: apostrophe, send: 3 }
     ```
  3. 保存后执行快捷键 `Ctrl + Alt + \` 重新部署。
- **效果**：配置变动完全独立解耦，后续直接使用 Git 拉取更新雾凇拼音仓库代码时不会产生合并冲突。

### 技巧 6：小狼毫 UI 高清适配与现代化皮肤定制

- **痛点场景**：Windows 下高分辨率（4K / 2K）屏幕缩放下，默认界面字体发虚、边框粗糙或候选窗口横竖排版不符合审美。
- **操作**：
  1. 在 `%APPDATA%\Rime` 目录下新建或编辑 `weasel.custom.yaml`。
  2. 指定横排显示、首选字体（如霞鹜文楷、微软雅黑或思源黑体）与现代配色：
     ```yaml
     # weasel.custom.yaml
     patch:
       # 强制候选框水平横排（true 为横排，false 为竖排）
       "style/horizontal": true
       # 内联嵌入（preedit 字符在输入框内显示）
       "style/inline_preedit": true
       # 字体与渲染调优
       "style/font_face": "LXGW WenKai, Microsoft YaHei"
       "style/font_point": 13
       # 选用暗色或浅色主题（内置预设主题或配色方案）
       "style/color_scheme": "nord"
     ```
  3. 保存后重新部署小狼毫，UI 即可换上高清晰度现代化外观。

### 技巧 7：多端词库同步与优雅的 Git 备份管理

- **痛点场景**：在多台 Windows 电脑或重装系统时，个人调频记录与自造词库丢失；
  如果将整个 `%APPDATA%\Rime` 丢进 Git 仓库，
  几十兆的编译二进制缓存文件会导致版本库庞大且冲突不断。
- **操作**：
  1. **配置内置同步（Sync）**：
     - 编辑 `%APPDATA%\Rime\installation.yaml`，指定独立设备名与云同步网盘目录：
       ```yaml
       installation_id: "desktop-win11"
       sync_dir: 'D:\Nutstore\RimeSync'
       ```
     - 右键小狼毫托盘图标选择“同步用户数据”，个人词频将自动导出为标准纯文本格式。
  2. **Git 版本库过滤规则**：
     - 若使用 Git 托管 `%APPDATA%\Rime`，务必创建 `.gitignore` 排除所有生成态缓存：
       ```gitignore
       # 忽略编译二进制产物
       /build/
       /*.bin
       # 忽略本地用户数据库（由 sync 机制接管，不宜直接进 git）
       /*.userdb/
       # 忽略安装信息与日志
       /installation.yaml
       /*.log
       ```
- **效果**：仅轻量化追踪纯文本 YAML 配置与词库补丁；
  设备间依赖纯文本词频同步，安全干净、无冲突风险。

## 四、维护排错与避坑指南

### 1. 修改配置后重新部署没有变化？

- **检查点 1（YAML 缩进陷阱）**：YAML 严格禁止使用 `Tab` 制表符作为缩进层级，
  且每一层必须是严格对应的空格数量。建议使用 VS Code 等现代编辑器并启用 YAML 校验插件。
- **检查点 2（语法报错排查）**：若 YAML 语法有误，Rime 编译会直接失败并保持原有旧二进制缓存。
  检查用户目录下的 `weasel.log` 或临时目录生成的编译日志查找具体报错行号。

### 2. 误输入错词被输入法记忆并高频出现？

- 输入该拼音直到错词出现在候选栏中。
- 使用方向键选中该错词高亮项。
- 直接按下 **`Shift + Delete`**。小狼毫将立即清除该词汇的用户词频加权。

### 3. 如何安全更新官方雾凇拼音仓库？

- 若 `%APPDATA%\Rime` 是通过 Git Clone 初始化的雾凇拼音：
  ```bash
  cd %APPDATA%\Rime
  git pull
  ```
- 由于个人配置全部写在 `*.custom.yaml` 和 `custom_phrase.txt` 中，
  `git pull` 不会产生代码冲突。更新完成后，按下 `Ctrl + Alt + \`
  即可完成无痛升级并享用最新流行词库。
