# Zoxide 常用命令速查与进阶技巧

> **工具说明**：`zoxide`（现代版 Autojump）是基于 Rust 编写的高性能目录跳转工具，通过访问频次与近期性（Frecency）智能匹配路径。当前配置已在 `~/.zshrc_local_after` 中通过 `eval "$(zoxide init zsh)"` 默认注入，主命令为 **`z`**，交互命令为 **`zi`**。

---

## 一、常用命令速查

### 1. 基础跳转与路径导航

| 命令 | 动作 | 说明 |
| :--- | :--- | :--- |
| `z <关键字>` | 跳转至最高权重路径 | 模糊匹配历史中权值（高频/最近访问）最高的目录 |
| `z <词1> <词2>` | 多关键字收敛匹配 | 多个关键词联合过滤，精准直达深层目录 |
| `z -` | 返回上一工作目录 | 兼容并取代原生 `cd -` |
| `z ..` | 返回上一级目录 | 兼容原生 `cd ..`（亦支持连续 `z ../..`） |
| `z /` 或 `z ./dir` | 绝对/相对路径直跳 | 兼容普通 `cd` 语法，无需切换心智 |

### 2. 交互式选择与搜索 (Interactive)

当前环境已深度集成 `fzf` 模糊搜索器：

| 命令 | 动作 | 说明 |
| :--- | :--- | :--- |
| `zi` | 打开全量交互式搜索 | 唤出 `fzf` 搜索完整历史目录库，支持即时过滤与跳转 |
| `zi <关键字>` | 带初始关键字交互搜索 | 预填关键字并展示候选子集，适合区分同名目录分支 |
| `zoxide query -i` | 交互式路径查询 | `zi` 的底层等同命令（仅查询并输出结果） |

### 3. 数据查询与权重统计 (Query & Scores)

| 命令 | 动作 | 说明 |
| :--- | :--- | :--- |
| `zoxide query -l` | 列出匹配目录列表 | 按权重从高到低纯文本列出所有已记录路径，适合管道处理 |
| `zoxide query -l -s` | **显示权重分值与统计** | 展示路径及其对应的 Frecency 得分，直观排查跳转优先级 |
| `zoxide query <关键字>` | 获取最佳匹配路径 | 仅输出匹配到的绝对路径字符串，不触发实际 `cd` 跳转 |

### 4. 数据库维护与清理 (Maintenance)

| 命令 | 动作 | 说明 |
| :--- | :--- | :--- |
| `zoxide add <路径>` | 显式添加目录 | 手动将指定目录写入数据库并增加权重（日常 `cd` 会自动记录） |
| `zoxide remove <路径>` | 移除指定路径 | 从数据库剔除已失效、废弃或迁移的目录路径 |
| `zoxide remove -i` | **交互式删除** | 调出 `fzf` 列表交互式勾选并剔除多余的过期路径 |
| `zoxide edit` | 直接编辑数据文件 | 调用默认文本编辑器直接修正历史数据库条目 |

## 二、进阶技巧

### 技巧 1：`zi` 联动生态内 `fzf` 打造交互式路径瞬移
* **痛点场景**：项目中常有大量结构相似的同名子目录（例如不同工程下的 `doc/`、`src/` 或 `configs/`），仅靠单个词盲跳容易进入非目标分支。
* **操作**：
  * 输入 **`zi <项目关键词>`**（例如 `zi dot`）。
  * 终端将立即调出当前配置好的 **`fzf`** 交互列表，输入任意片段即可快速筛选。
* **效果**：免去猜测优先级的成本，结合当前环境的模糊搜索直观挑选目标目录。

### 技巧 2：多级空格分词精准狙击深层目录（告别逐层 `cd`）
* **痛点场景**：工作区嵌套过深（如 `~/dotfiles/vim/pack/vendor/start/vimtex`），即使 Tab 补全也需要逐级敲击。
* **操作**：
  * 无需输入完整长路径，提取路径关键节并以**空格分隔**：
    ```bash
    z dot vim pack
    ```
* **效果**：`zoxide` 会自动求多关键字交集并匹配最深的符合路径，一次击键即刻深层直达。

### 技巧 3：结合 Tmux 新窗口/分屏快速建构工作区
* **痛点场景**：在多任务并发处理时，需要在另一个常用工程中快速拉起新的 Tmux 窗口或分屏进行对照开发。
* **操作**：
  * 在任意终端窗格中，先执行 `z <目标工程>` 跳转到指定目录。
  * 配合当前 Tmux 配置按下 **`Prefix + c`**（新建窗口）或 **`Prefix + %` / `Prefix + "`**（分屏）。
* **效果**：当前 Tmux 配置已绑定 `pane_current_path`，新建的窗口/分屏将**自动继承**并锁定在该目标目录，实现“一次瞬移，全套工作区分屏就绪”。

### 技巧 4：脚本与命令行管道协同（告别绝对路径硬编码）
* **痛点场景**：编写临时自动化脚本或单行命令打包文件时，若写死绝对路径，换台机器往往因为用户名或挂载点不同而失效。
* **操作**：
  * 利用 `zoxide query` 动态获取最佳路径：
    ```bash
    tar -czvf dot-docs.tar.gz "$(zoxide query dot)/docs"
    ```
* **效果**：动态解析并拼接高频目录，实现多设备环境下跨机器无缝复用命令。

### 技巧 5：脏数据剔除与保持数据库敏捷
* **痛点场景**：项目目录被删除或重命名后，历史库中的旧记录仍然拥有极高权重，导致常用词经常跳转到已不存在的路径。
* **操作**：
  * 发现失效路径后，执行 **`zoxide remove -i`**。
  * 在弹出的 fzf 菜单中选择失效项并回车确认删除。
* **效果**：即刻清除脏数据，让权重分配重新回归当前实际工作流，保持匹配预测敏捷准确。
