# Vim 插件使用手册

日常插件快捷键与功能速查。
Vim 的 `<Leader>` 键为默认的反斜杠 `\`。

## fzf.vim

基于 fzf 与 ripgrep 的文件检索套件。
配置文件：[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)

### 快捷键

- `<C-p>`：查找项目文件，右侧显示预览。
- `;`：查找并切换已打开的 buffer。
- `\A`：全局检索项目文本（调用 ripgrep）。
- `\K`：搜索光标下的词。
- `K`：悬浮查看光标下符号的文档（由 CoC 提供）。

### 弹窗操作

- `<C-j>` / `<C-k>` 或方向键：上下移动光标。
- `<CR>`：在当前窗口打开。
- `<M-v>`（即 Alt-v）：垂直分屏打开（避开终端 Ctrl-V 粘贴冲突）。
- `<M-s>`（即 Alt-s）：水平分屏打开。
- `<C-t>`：在新标签页打开。
- `<Esc>` 或 `<C-c>`：退出弹窗。

### 常用命令

- `:History`：查看最近打开过的文件列表。
- `:Lines`：在所有已加载 buffer 中搜寻文本行。
- `:BLines`：在当前文件中搜寻文本行。
- `:Commits` / `:BCommits`：交互式浏览提交历史并预览 diff。
- `:Marks`：查看并跳转 Vim 书签。

## coc.nvim

LSP 代码补全、诊断与扩展平台。
配置文件：[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)

### 补全与代码片段

- `<Tab>`：
  补全菜单打开时向下选词；
  在代码片段内时跳到下一个占位符；
  光标前为空白字符时插入缩进；
  其他情况触发补全。
- `<S-Tab>`：补全菜单打开时向上选词；在片段内跳到上一个占位符。
- `<CR>`：确认选中补全项。
- `<C-Space>`（终端下为 `<C-@>`）：手动呼出补全菜单。

### 代码导航与重构

- `gd`：跳转到定义。
- `gy`：跳转到类型定义。
- `gi`：跳转到实现。
- `gr`：查找引用。
- `K`：悬浮窗口查看函数签名与文档注释。
- `\rn`：变量或函数重命名。
- `\qf`：修复当前行诊断问题。
- `\f`：格式化选中的代码。
- `:Format`：格式化当前文件（保存时会自动格式化）。
- `:OR`：整理 import（移除未使用的导入）。
- `[g` / `]g`：跳到上一个 / 下一个诊断（错误或警告）。

### 命令与列表（<Space> 前缀）

- `<Space>a`：打开诊断列表（`:CocList diagnostics`）。
- `<Space>o`：打开当前文件大纲（`:CocList outline`）。
- `<Space>s`：搜索工作区符号（`:CocList -I symbols`）。
- `<Space>c`：打开命令面板（`:CocList commands`）。
- `<Space>e`：管理扩展（`:CocList extensions`）。
- `<Space>g`：打开改动文件列表（`:CocList --normal gstatus`）。
- 列表内导航：`<Space>j` 下一项，`<Space>k` 上一项，`<Space>p` 恢复上次列表。
- `:Fold`：调用 CoC 语言服务器（如 `coc-json`）计算当前文件的语法折叠范围。

### Git 集成（coc-git）

侧边栏与状态栏：

- 符号列：`+` 为新增，`~` 为修改，`_` 为删除。
- 状态栏显示分支名与改动计数（如 `master* +2 ~1 -0`）。

变更跳转与操作：

- `[c` / `]c`：跳到上一个 / 下一个 diff 改动块。
- `[C` / `]C`：跳到上一个 / 下一个合并冲突块。
- `\gp`：浮窗预览当前块改动前的代码。
- `\gb`：查看当前行代码的提交记录（blame）。
- `\gu`：撤销当前块的改动。
- `\gs`：暂存当前块（相当于单块 git add）。
- `\gd`：左右分屏对比当前文件与暂存区。
- `:CocCommand git.browserOpen`：在浏览器打开当前行对应的仓库链接。
- `:CocCommand git.foldUnchanged`：折叠未修改的行，仅展示变动。

## vim-easymotion

屏幕可视区域光标快速跳转。
配置文件：[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)
已开启 smartcase，输入小写可匹配大写。
跳转前缀默认为 `\\`（即双击 Leader 键）。

### 常用跳转

- `\\s`：输入两个字符，按目标位置出现的字母标签直达。
- `\\w`：跳到后方单词开头。
- `\\b`：跳到前方单词开头。
- `\\e`：跳到后方单词结尾。
- `\\j`：向下跳行（每行行首生成标签）。
- `\\k`：向上跳行（每行行首生成标签）。
- `\\f{char}`：向后查找单字符并标记跳转。
- `\\F{char}`：向前查找单字符并标记跳转。

### 搜索联动（incsearch）

- `z/`：正向搜索，回车后在匹配处生成标签直达。
- `z?`：反向搜索联动。
- `zg/`：原位搜索联动。

### 配合操作符

可作为移动动作与 `d`（删除）、`c`（修改）、`y`（复制）组合：

- `d\\w` + 目标标签：从光标处删除到目标单词。
- `c\\s` + 两个字符 + 目标标签：修改光标到目标位置的内容。
- `y\\j` + 目标标签：复制当前行到目标行。

## vim-visual-multi

多光标同时编辑支持（类似 VS Code 的 Ctrl-D 多光标功能）。
配置文件：[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)
前缀键已定制为 `\v`（避免与 EasyMotion 的 `\\` 冲突）。

### 1. 启动多光标

- `<C-n>`：
  普通模式下选中光标所在的词；
  继续按 `<C-n>` 向后查找并选中下一个相同的词添加光标。
- `v` 选中文本后按 `<C-n>`：
  将选中的子串作为匹配目标，继续按 `<C-n>` 添加下一个匹配光标。
- `\vj` / `\vk`（或 `<C-Down>` / `<C-Up>`）：
  向下 / 向上在当前列垂直新增一个光标。
- `\vA`：选中当前文件中所有与当前词相同的匹配项并开启多光标。
- `\vc`（可视模式）：
  按 `V` 选中多行后按 `\vc`，在所选每行的开头直接生成一列光标。

### 2. 多光标下的操作与编辑

进入多光标状态后，大部分 Vim 操作会自动应用到所有光标：

- `<Tab>`：在「光标模式」（普通模式）与「选区模式」（可视模式）间切换。
- `i` / `a`：在所有光标处进入插入模式，输入内容实时同步。
- `c`：修改选中文本（删除选区并进入插入模式）。
- `d` / `x`：删除所有光标处的字符或选区。
- `n` / `N`：在多光标模式下跳转到下一个 / 上一个匹配项。
- `q`：跳过当前高亮匹配项，寻找下一个。
- `Q`：取消当前位置的光标。
- `<Esc>`：完全退出多光标模式，恢复为单光标。

## lightline.vim（输入法状态与模式联动）

状态栏输入法状态显示与中英文自动切换。
配置文件：[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)
依赖工具：`im-select.exe`（已内置于 `dotfiles/bin/`）。

### 1. 状态栏呈现说明

在 Lightline 右侧信息区设立独立高亮色块：

- `[zh]`：表示当前处于中文输入法状态。
- `[en]`：表示当前处于英文输入法状态。
- 普通模式（Normal）与插入模式（Insert）下均实时显示。

### 2. 中英文自动切换机制

- **退出插入模式（`<Esc>`）**：
  自动保存当前输入法状态，并将 Windows 输入法切回英文。
  避免在普通模式下移动或执行操作时误触中文输入法。
- **进入插入模式（`i` / `a` 等）**：
  自动恢复上次在插入模式的输入法（若先前为中文则切回中文）。
- **打字中手动按 Shift 切换**：
  在插入模式输入停顿后，后台异步更新 Lightline 上的 `[zh]` / `[en]`。

## 代码折叠（Fold）

缓冲区代码折叠与层级浏览。
配置文件：[vimrc](file:///home/laukalin/dotfiles/vimrc)、[vimrc_plugin](file:///home/laukalin/dotfiles/vimrc_plugin)
当前 `vimrc` 默认设置 `nofoldenable`，可通过以下快捷键或命令按需启用。

### 折叠开闭与切换

- `za`：切换当前光标所在折叠的开闭状态。
- `zo`：打开当前折叠。
- `zc`：关闭当前折叠。
- `zA`：递归切换当前块及其所有子折叠。
- `zO`：递归打开当前块内的所有子折叠。
- `zC`：递归关闭当前块内的所有子折叠。

### 全局与层级控制

- `zR`：打开全局所有折叠，平铺展示全文。
- `zM`：关闭全局所有折叠，仅保留顶层结构。
- `zr`：减少一级折叠深度，展开更深一层。
- `zm`：增加一级折叠深度，收起一层嵌套。
- `zi`：翻转折叠开关，临时在折叠与全平铺视图间切换。

### 折叠间光标跳转

- `zj`：跳到下一个折叠的开头。
- `zk`：跳到上一个折叠的开头。
- `[z`：跳到当前已打开折叠的起始行。
- `]z`：跳到当前已打开折叠的结束行。

### 语法折叠命令

- `:Fold`：调用 CoC 语言服务器（如 `coc-json`）计算当前文件的语法折叠范围。
