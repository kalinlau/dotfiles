# Vim 插件实战使用手册

本文档为个人实战插件用法速查手册。

> [!NOTE]
>
> - **全局按键提示**：配置中使用 Vim 默认的 `<Leader>` 前缀键，即键盘上的 **`\`**（反斜杠）。
> - **维护规则**：每个插件独立占用一个二级标题（`## <插件名>`），后续插件的学习记录与用法总结依次 append 到本文档最后。

## fzf.vim

- **定位**：基于外部模糊搜索利器 `fzf` 与全局搜索后端 `ripgrep` 的现代高性能检索套件。
- **配置位置**：[`vimrc_plugin`](file:///home/laukalin/dotfiles/vimrc_plugin) 中的 `" ----- fzf & fzf.vim -----` 配置段。

### 1. 核心快捷键速查

| 需求场景                   |             快捷键             | 映射命令            | 操作说明                                                                       |
| :------------------------- | :----------------------------: | :------------------ | :----------------------------------------------------------------------------- |
| **模糊搜索文件**           |          **`<C-p>`**           | `:Files`            | 屏幕中央弹出浮动窗口，输入文件名关键词进行模糊匹配，右侧实时显示代码高亮预览。 |
| **切换 Buffer 缓冲区**     |            **`;`**             | `:Buffers`          | 列出当前所有已打开的缓冲区，支持即时预览与快速切换。                           |
| **全局内容搜索 (ripgrep)** | **`<Leader>A`**<br>_(即 `\A`)_ | `:Rg `              | 呼出全局文本检索，直接输入代码或正则，边打字边动态搜索全项目。                 |
| **快速搜索光标下的词**     | **`<Leader>K`**<br>_(即 `\K`)_ | `:Rg <单词>`        | 光标停在某个变量名或函数名上时直接按下，立即全项目查找所有出现位置。           |
| **查看函数/变量的文档**    |            **`K`**             | `ShowDocumentation` | （保留给 CoC LSP）光标停在符号上直接按 `K`，弹出类型定义与说明文档悬浮窗。     |

### 2. FZF 弹窗内通用交互手势

在任何 FZF 弹出的浮窗（搜文件、搜 Buffer、全局搜代码）内：

- **移动选择**：`<C-j>` / `<C-k>` 或方向键上下移动高亮条。
- **确认打开方式**：
  - **`<Enter>`**：在当前窗口直接打开选中的文件/行。
  - **`<C-v>`**：在**垂直分屏**（vertical split）中打开。
  - **`<C-x>`**：在**水平分屏**（split）中打开。
  - **`<C-t>`**：在**新标签页**（tab）中打开。
- **退出弹窗**：按 **`<Esc>`** 或 **`<C-c>`** 取消并关闭浮窗。

### 3. 常用内置进阶命令（底行模式直接执行）

- **`:History`**：列出最近打开与编辑过的文件历史（MRU 列表）。
- **`:Lines`**：在当前所有已加载的 Buffer 内部模糊查找某一行。
- **`:BLines`**：在**当前打开的文件**中模糊搜索某一行（针对超长单文件极为高效）。
- **`:Commits` / `:BCommits`**：以交互式浮窗浏览 Git 提交日志，并在右侧实时查看对应 commit 的 diff 细节。
- **`:Marks`**：直观查看并跳转当前在 Vim 中设置的所有书签（Marks）。

## coc.nvim

- **定位**：全功能语言服务器协议（LSP）平台、智能补全引擎与 Snippets 代码片段调度中心。
- **配置位置**：[`vimrc_plugin`](file:///home/laukalin/dotfiles/vimrc_plugin) 中的 `" ----- coc-nvim -----` 配置段。

### 1. 智能 `<Tab>` / `<S-Tab>` 补全与片段连击流

移除了老旧冲突的 `supertab` 之后，`<Tab>` 键已由 `coc-snippets` 全面接管，实现现代化编辑器的多合一交互：

| 触发场景               |                 按键                  | 行为表现                                                                              |
| :--------------------- | :-----------------------------------: | :------------------------------------------------------------------------------------ |
| **补全菜单已弹出**     |              **`<Tab>`**              | **下选**：高亮并选择下一个候选词。                                                    |
|                        |             **`<S-Tab>`**             | **上选**：高亮并选择上一个候选词。                                                    |
|                        |          **`<CR>`** _(回车)_          | **确认**：选定当前高亮项并关闭补全菜单。                                              |
| **代码片段 (Snippet)** |              **`<Tab>`**              | **展开 / 下一步**：若输入了代码片段前缀则立即展开；处于片段内时跳到下一个参数占位符。 |
|                        |             **`<S-Tab>`**             | **上一步**：在代码片段参数占位符之间向后倒退。                                        |
| **普通缩进**           |              **`<Tab>`**              | 光标前方为行首或空格时，执行正常的缩进插入。                                          |
| **手动唤出补全**       | **`<C-Space>`**<br>_(终端下 `<C-@>`)_ | 强制弹出 LSP 智能补全建议菜单。                                                       |

### 2. 代码导航、重构与诊断快捷键

| 需求场景           |       快捷键        | 对应动作                       | 说明                                               |
| :----------------- | :-----------------: | :----------------------------- | :------------------------------------------------- |
| **跳转定义**       |      **`gd`**       | `<Plug>(coc-definition)`       | 直达光标所在符号的源码定义处。                     |
| **跳转类型**       |      **`gy`**       | `<Plug>(coc-type-definition)`  | 跳转到变量或对象的类型定义（Type Definition）。    |
| **跳转实现**       |      **`gi`**       | `<Plug>(coc-implementation)`   | 跳转到接口的具象实现（Implementation）。           |
| **查找引用**       |      **`gr`**       | `<Plug>(coc-references)`       | 查找当前符号在全项目中的全部引用。                 |
| **文档与类型提示** |       **`K`**       | `ShowDocumentation()`          | 在光标旁弹窗显示函数签名、JSDoc / 文档注释。       |
| **符号重命名**     |  **`<Leader>rn`**   | `<Plug>(coc-rename)`           | 项目级变量/函数批量重命名。                        |
| **快速修复**       |  **`<Leader>qf`**   | `<Plug>(coc-fix-current)`      | 对当前行报出的语法/类型错误执行 Quickfix 建议。    |
| **选区格式化**     |   **`<Leader>f`**   | `<Plug>(coc-format-selected)`  | 选中一段代码后执行格式化。                         |
| **全文格式化**     |    **`:Format`**    | `CocActionAsync('format')`     | 一键格式化当前整个文件（已开启保存自动格式化）。   |
| **组织导入**       |      **`:OR`**      | `editor.action.organizeImport` | 自动整理当前文件的 import 依赖（去除未使用导入）。 |
| **诊断信息跳转**   | **`[g`** / **`]g`** | Diagnostic Prev / Next         | 在当前文件的上一个/下一个错误或警告间跳转。        |

### 3. CocList 列表交互（`<Space>` 前缀）

CoC 内置了极具生产力的交互式命令面板：

- **`<Space>a`**：打开诊断列表（`:CocList diagnostics`），汇总查看当前缓冲区的错误与警告。
- **`<Space>o`**：打开大纲面板（`:CocList outline`），以树状结构查看当前文件的函数、类与属性。
- **`<Space>s`**：搜索工作区符号（`:CocList -I symbols`），全项目定位类名或方法名。
- **`<Space>c`**：打开命令面板（`:CocList commands`），执行各类 CoC 扩展命令。
- **`<Space>e`**：管理扩展插件（`:CocList extensions`）。
